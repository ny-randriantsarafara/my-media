# CI/CD — implementation plan

> Spec: `docs/superpowers/specs/2026-10-11-cicd-design.md`. Steps checked off as work completes.

**Goal:** Required CI on `main`, previews per PR, automatic staging, manually promoted production, on the `vps-services` platform.

**Constraints:**

- Actions pinned by full SHA, minimal permissions, `persist-credentials: false`.
- No secrets in Git or logs. Keys and passwords generated locally, sent to GitHub secrets, readable copy outside Git at `0600`.
- Platform changes in `vps-services`, via PR from this repo. Product changes in `my-media`.
- Branches `feat/`, `fix/`, or `chore/`. Commits use Conventional Commits in English.
